# SEO Standards
Version: 1.0
Project: LowKeyDevs

---

# Purpose

This document defines the SEO standards for every page on LowKeyDevs.

Every tool, landing page, category page, blog article, documentation page, and future feature MUST follow these standards.

The goal is not keyword stuffing.

The goal is to become the most useful result for the user's search intent while maintaining excellent technical SEO, accessibility, and performance.

SEO decisions must never negatively affect user experience.

The tool always comes before SEO.

---

# Core Philosophy

LowKeyDevs follows these principles.

1. User-first, search-engine-friendly.
2. Fast pages rank better than bloated pages.
3. Helpful content beats longer content.
4. Content supports the tool rather than replacing it.
5. Every page must answer the user's search intent immediately.
6. Never create content purely for ranking.
7. Never sacrifice usability for SEO.

---

# Search Intent

Every page MUST target exactly ONE search intent.

Examples

Informational
"What is Base64?"

Tool
"Base64 Encoder"

Comparison
"PNG vs JPG"

Tutorial
"How to convert PNG to WebP"

Never mix multiple intents on the same page.

# URL Standards

URLs must

- be lowercase
- contain hyphens
- never contain underscores
- never contain dates
- never contain random IDs
- remain permanent once published

Good

/tools/json-formatter

Bad

/tools/jsonFormatter123

Length

140–160 characters

Requirements

# Performance

SEO must never reduce performance.

Target

LCP < 2.5 s

CLS < 0.1

INP < 200 ms

Avoid unnecessary hydration.

Avoid excessive JavaScript.

Prefer Astro islands.
